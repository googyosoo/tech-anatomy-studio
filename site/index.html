Google Gemini API Key 설정

Bring Your Own Key (선택 사항)

완전한 프라이버시 보장: 입력하신 API 키는 오직 브라우저의 localStorage에만 보관되며, 어떠한 외부 서버로도 전송되지 않고 Google Gemini API 엔드포인트와 직접 통신합니다.

* API 키가 없어도 9종의 핵심 마스터피스 프리셋과 내장 룰베이스 합성 엔진은 100% 무료로 무제한 사용할 수 있습니다. 키를 등록하시면 임의의 자연어 프롬프트를 Gemini 2.0 Flash가 더욱 심도 있는 기계 메타포로 분석하여 생성합니다.

Google AI Studio (aistudio.google.com)에서 무료 발급받을 수 있습니다.
